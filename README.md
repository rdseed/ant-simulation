# Anthill Simulation (2D Симуляция Муравейника)

Графическое 2D-приложение на C++ и GTKmm 4, симулирующее жизнедеятельность муравейника, поведение разных типов муравьев, сбор ресурсов, расширение колонии и защиту от врагов.

## Особенности проекта

* **Модульная графика на Cairo:** Рендеринг игрового поля и объектов в реальном времени с использованием возможностей Cairo и `Gtk::DrawingArea`.
* **Разделение ролей муравьев (ИИ):**
  * **Собиратели (Harvesters):** Ищут еду на карте и приносят её в муравейник. Еда необходима для появления новых особей.
  * **Строители (Builders):** Собирают строительные материалы. Материалы увеличивают физический размер муравейника и его максимальную вместимость (популяцию).
  * **Воины (Warriors):** Патрулируют территорию и атакуют появляющихся врагов ценой собственной жизни.
* **Враждебные существа:**
  * **Враги (Enemies):** Спавнятся на карте, охотятся на рабочих муравьев и уничтожают их.
* **Интерактивное управление и симуляция:**
  * Изменение скорости симуляции «на лету».
  * Ручной спавн еды, материалов и врагов по кнопке.
  * Настройка автоспавна ресурсов и врагов с возможностью регулировки частоты спавна.
* **Гибкие настройки и сохранение:**
  * Параметры симуляции (начальная популяция, автоспавн, скорость) сохраняются в бинарный файл `options.bin` и загружаются при старте.
* **Кастомный UI:** Полноценный интерфейс (Главное меню, Окно симуляции, Настройки) с поддержкой кастомных CSS-стилей для GTK 4.



## Технологии

* **Язык программирования:** C++17
* **GUI Фреймворк:** GTKmm 4.0 (`gtkmm-4.0`)
* **2D Векторная графика:** Cairo
* **Система сборки:** Make / CMake / GCC



## Архитектура проекта

Код структурирован по паттерну близкому к MVC и разделен на логические модули:

* `ants.h / ants.cpp` — математическая модель и логика поведения всех агентов (Муравейник, Собиратели, Строители, Воины, Враги, Ресурсы).
* `simulation.h / simulation.cpp` — менеджер симуляции: циклический таймер, обновление статистики и отрисовка кадра через Cairo.
* `scenes.h / scenes.cpp` — верстка и UI-сцены (Главное меню, Симуляция, Настройки).
* `mainwindow.h / mainwindow.cpp` — главное окно программы, управление переключением между сценами.
* `options.h / options.cpp` — сериализация параметров симуляции в бинарный файл и их чтение.

## Как пользоваться

Главное меню: Позволяет перейти к симуляции или настроить параметры.

Настройки (Options): Настройте начальную популяцию, включите/выключите автоматический спавн ресурсов и задайте интенсивность появления врагов, затем нажмите Save.

Симуляция (Simulation):

* Наблюдайте за развитием колонии в реальном времени.

* Используйте слайдер для изменения скорости процессов.

* Добавляйте ресурсы вручную кнопками Add Food, Add Material, Add Enemy.
